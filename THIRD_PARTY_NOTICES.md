# Third-Party Notices

Portus MCP uses third-party npm packages.

Runtime dependencies are listed in `package.json` and locked in `package-lock.json`.

## Flue

Portus MCP uses Flue for spawned agent support only.

Direct MCP project tools still work without using spawned agents.

Packages:

```text
@flue/cli
@flue/sdk
```

Project:

```text
https://github.com/withastro/flue
```

License:

```text
Apache-2.0
```

## Screenshot Capture

Portus MCP uses `node-screenshots` for native session-window enumeration and capture, and `sharp` for bounded resizing and JPEG quality control.

Packages:

```text
node-screenshots@0.2.8
sharp@0.35.3
```

Projects:

```text
https://github.com/nashaofu/node-screenshots
https://github.com/lovell/sharp
```

License:

```text
Apache-2.0
```
